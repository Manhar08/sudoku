# Sudoku — Private Puzzle Collection

A free, open-source, ad-free Sudoku web app with 120 original puzzles (40 Easy, 40 Medium, 40 Hard), private login, notes, undo/redo, timer, mistake tracking, progress tracking and light/dark mode.

## Features
- Login-protected pages (signed, HTTP-only session cookie; 30-day persistence)
- 120 unique puzzles, each with a single valid solution
- Puzzle picker + Random Puzzle per difficulty
- Keyboard + on-screen number pad, notes/pencil mode, undo/redo, erase
- Unlimited-time timer with pause/resume; mistakes counter (no game over)
- Check, Finish, Restart, Show Solution
- Progress saved in the browser (completed puzzles, best time, total time, streak, recent games); in-progress games resume automatically
- Light/dark theme (remembered), responsive, accessible

## Tech
React 19, TanStack Start, Vite, Tailwind CSS — all open source.

## Running locally
```bash
bun install        # or npm install
cp .env.example .env   # then fill in values
bun run dev
```
Build for production: `bun run build`.

## Authentication & environment variables
| Variable | Purpose |
|---|---|
| `APP_USERNAME` | Login username (defaults to `manhar08`) |
| `APP_PASSWORD` | Login password — server-only, never shipped to the browser |
| `SESSION_SECRET` | Long random string used to sign session cookies |

The password is only read on the server and compared in constant time against SHA-256 digests; it never appears in source code or browser JavaScript. `.env` is git-ignored.

### Changing the password
Update the `APP_PASSWORD` secret (in `.env` locally, or in your host's secret settings) and restart/redeploy. To log out all existing sessions too, also change `SESSION_SECRET`.

## Adding puzzles
Puzzles live in `src/data/puzzles.json` as `{ id, difficulty, puzzle, solution }`, where `puzzle` and `solution` are 81-character strings (row by row, `0` = empty). Regenerate the whole set with:
```bash
python3 scripts/generate_puzzles.py
```
The generator guarantees every puzzle has exactly one solution and no duplicates.
